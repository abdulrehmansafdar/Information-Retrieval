# Relevance judgements for the week02 corpus of 20 research papers.
#
# Format
#   <query_id> <paper_id> <0 or 1>
#
# A 1 means an assessor judged that paper to ANSWER that query. A 0 means an
# assessor looked at it and judged that it does not. The 0s are the hard part
# of a qrels file and the part most often left out; without them a system that
# returns one paper and happens to be right scores 1.0, and recall and MAP are
# simply undefined.
#
# A query text is given in a comment above each block.
#
# How these were judged
#   Binary relevance, judged by hand against the title, abstract, methodology
#   and results of each paper. A paper that USES a term in passing is not
#   relevant to a query about that term: q07 asks about the evaluation metrics
#   and p16 is marked 0 even though its results section reports "mean average
#   precision", because p16 is about term weighting and merely borrows the
#   metric to report its own numbers.
#
# What these judgements are NOT
#   Twelve hand-made queries over twenty papers is a demonstration, not a
#   benchmark. Nothing here supports a claim about which retrieval model is
#   better in general. What it does support is "on these twelve queries, with
#   these judgements, model X found more relevant papers than model Y".

Data Science and Machine Learning

Data science is the practice of turning raw information into a useful decision. The work has four parts: collecting the right data, cleaning it, exploring it and presenting a conclusion in a way that a non specialist can understand. Machine learning is one tool inside this larger process, and it supplies the prediction or the classification that appears in the final report. A data scientist therefore needs technical skill in programming and statistics, but also the ability to ask a sensible question of the business. Many projects fail at the cleaning stage, because a data set contains duplicate records, missing values and inconsistent names. Good documentation allows another person to repeat the analysis later, and clear visualisation of the result helps a decision maker to judge how much trust to place in a model that nobody can explain.

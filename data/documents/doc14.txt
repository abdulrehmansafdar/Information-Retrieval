Cybersecurity and Artificial Intelligence

Cybersecurity protects computers, networks and digital information from attack, and machine learning is now used to strengthen that protection. A modern security system collects a very large amount of log data from the network and analyses it continuously. An algorithm learns the normal behaviour of the software and of its users, so an anomaly that has never been seen before can still be reported. This kind of anomaly detection is valuable because new attacks appear every week and no manual rule can be written for each of them. The same information is used to classify suspicious messages and to block them before they reach a user. There are limits. An attacker may feed false data to the model, and an automatic system can block a legitimate service. Security teams therefore keep human supervision and test every tool before it joins a real network.

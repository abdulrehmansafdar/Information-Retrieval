Machine Learning

Machine learning is the part of artificial intelligence in which a computer system improves automatically by studying examples instead of being programmed with explicit rules. A learning algorithm examines a large data set, detects recurring patterns and stores what it finds in a statistical model. When new data arrives, the model uses that knowledge to make a prediction or to classify an unknown case. The three widely used families are supervised learning, unsupervised learning and reinforcement learning. In practice the workflow is always similar: collect data, clean it, choose features, train the model, test the result and repeat. Good engineering practice is needed because a poorly prepared data set produces a weak model even when the mathematics is correct. Machine learning now supports many applications, including recommendation systems, medical prediction tools, fraud detection and language technology.

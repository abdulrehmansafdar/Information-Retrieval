Machine Learning for Cybersecurity

Machine learning for cybersecurity turns stored network information into an early warning system. A model is trained on a large data set of historical traffic, and it learns the pattern of normal communication between computers. This anomaly detection is valuable when the model observes behaviour that does not fit the pattern, since it can report the problem to a security analyst at once. Some systems go further and use classification to decide whether an alert is an intrusion attempt or a harmless software update. Because a security team receives thousands of alerts each day, this ranking of information saves a great deal of time. The main difficulty is that an attacker can also study the system and try to hide inside the normal pattern, so models must be retrained and compared with the newest attack data. Encryption protects the data itself, but machine learning helps to notice when something is wrong.
